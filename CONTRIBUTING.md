# Contributing to aicontainer

Thank you for your contribution. aicontainer is deliberately small: a lean,
auditable devcontainer for AI coding tools in bypass / auto-approve mode.
Keep this goal in mind when you propose a change.

## Before you start

1. Read the [threat model](docs/user/security.md). Evaluate every change to
   `template/` against it.
2. Read [Development](docs/contributing/development.md): the dev setup,
   coding conventions, how to submit a change, and what we do not merge.
3. Read the [contributor guide](docs/README.md#contributor-guide) page for the
   area that you change. Each page lists the rules that you must keep and the
   tests that guard them.

AI coding agents: start at [AGENTS.md](AGENTS.md).

## Reporting security issues

Do **not** open a public issue for a security finding. Use **GitHub's private
security advisory** flow on this repository (Security → Advisories → "Report
a vulnerability"). Only the maintainer can see it. We acknowledge reports in
72 hours.

## Code of conduct

When you participate in this project, you agree to obey the
[Code of Conduct](CODE_OF_CONDUCT.md).
